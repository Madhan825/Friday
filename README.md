# Friday (Android)
Build: Android Studio-ல இந்த folder-ஐ Open → Build > Build APK(s). (அல்லது GitHub-ல push பண்ணா Actions தானா APK தரும்.)
Setup: app திறந்து Gemini API key → Save → Permissions → Accessibility ON → Battery → START. "Friday, ..." ன்னு பேசுங்க.
மற்ற device: அதிலயும் இதே APK; "tv=ip" சேர்த்து, token-ஐ அந்த device-லயும் ஒரே மாதிரி வைங்க.
